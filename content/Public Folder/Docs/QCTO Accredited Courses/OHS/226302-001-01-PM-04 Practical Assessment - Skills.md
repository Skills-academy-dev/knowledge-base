PA01-01: Create Files and Categorise Them Using an Acceptable File
Classification System
1. Select and Define Classification System:
o System Choice: Use categories like "Incident Reports," "RiskAssessments,"
"Training Records," and "Safety Policies."
o Criteria: Define how files are categorized (e.g., by type of document,date,
department).
2. Create and Label Files:
o Create Files: Prepare manila folders for each category.
o Labeling: Label each folder with clear, specific categories (e.g., "Incident Reports
– 2024," "Training Records – Safety Courses").
o Include Documentation: Place a cover sheet inside each folder with file details
like title, creation date, and brief description.
