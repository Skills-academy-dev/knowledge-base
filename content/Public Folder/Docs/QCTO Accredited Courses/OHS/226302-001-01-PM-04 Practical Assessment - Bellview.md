PM-04-PS01 CORRECTLY USE MANUAL FILING

SYSTEMS

Complete the following activities in the presence of your facilitator/instructor who must observe the

activity and complete the attached observation evaluation form.

Activity 1

In this practical task, you will be required to demonstrate your ability to correctly use manual filing

systems in your role as an Occupational Health and Safety Practitioner.

This practical is part of learning whose focus is on providing the learner an opportunity to practice

the skills required to administer the key OHS activities for an OHS function.

You will be provided with a simulated or controlled working environment with all the tools,

equipment and physical requirements to execute the skill.

Scenario-Based Practical Task: Using Manual Filing Systems in an Office Setting

Scenario Overview

In this simulated office environment, you are tasked with managing a manual filing system for

Occupational Health and Safety (OHS) documentation. Your goal is to demonstrate effective use

of manual filing systems by creating and categorizing files, controlling access, placing and

retrieving documents, maintaining a filing index, and archiving files.

Simulated Office Environment Setup

Environment:

● Office Layout:

o Filing Area: Contains a set of filing cabinets, a desk with filing materials, and an

archival storage area.

o Common Areas: Includes spaces where you might find or place documents (e.g.,

desks, meeting rooms).

11

Filing Materials:

● Filing Cabinets: Equipped with drawers for different categories.

● Folders: Manila folders in various colors (e.g., blue for safety reports, red for incident

reports).

● Labels: For categorizing files.

● Index Cards: For building the filing index.

● Archive Boxes: For long-term storage of files.

● Document Control Forms: Templates for managing document access.

Staging:

● Incident Reports: Simulated recent incident reports in a mixed pile.

● Risk Assessments: A stack of risk assessments that need to be filed.

● Training Records: Documents related to employee training programs.

● Outdated Files: Files that need to be archived.

Tasks and Execution

PA01-01: Create Files and Categorise Them Using an Acceptable File

Classification System

1\. Select and Define Classification System:

o System Choice: Use categories like "Incident Reports," "RiskAssessments,"

"Training Records," and "Safety Policies."

o Criteria: Define how files are categorized (e.g., by type of document,date,

department).

2\. Create and Label Files:

o Create Files: Prepare manila folders for each category.

o Labeling: Label each folder with clear, specific categories (e.g., "Incident Reports

– 2024," "Training Records – Safety Courses").

o Include Documentation: Place a cover sheet inside each folder with file details

like title, creation date, and brief description.

12

PA01-02: Apply a Logical Process for Controlling Access to Files and Use an Acceptable

Document Control Process and Codes

1\. Control Access:

o Access Log: Create an access log with columns for file name, access date, user,

and purpose of access.

o Access Policy: Develop a policy detailing who can access which files and under

what conditions (e.g., only authorized personnel can access confidential files).

2\. Document Control Process:

o Control Codes: Develop a coding system (e.g., IR-2024-001 for Incident Report

2024-001).

o Tracking System: Use document control forms to record movements and updates

of files.

PA01-03: Apply a Logical Process for Placing New Documents in Files and Recalling

Files for Dated Follow-Up Work

1\. Placing New Documents:

o Sort Documents: Organize new documents by category.

o File Placement: Place each document in the appropriate folder and update the

access log if necessary.

2\. File Retrieval:

o Follow-Up Work: Use the filing index to locate and retrieve files for follow-up

actions.

o Update Log: Record the retrieval and update the status of the file in the access

log.

PA01-04: Build and Maintain an Easy-to-Use Filing Index

1\. Create Filing Index:

o Design Index: Create an index using index cards or a filing index book.

o Index Entries: Include file categories, file names, and locations (e.g., "Incident

Reports – Drawer 1, Folder 3").

2\. Maintain the Index:

o Regular Updates: Periodically update the index to reflect new files and changes.

o Accuracy Check: Regularly review and verify the accuracy of the index.

13

PA01-05: Apply an Acceptable Process for Archiving Files

1\. Archiving Files:

o Selection Criteria: Identify files that are no longer active but need to be retained

(e.g., incident reports older than two years).

o Archival Process: Place selected files in labeled archive boxes,indicating

contents and date, and store them in a designated archival area.

2\. Archival Records:

o Archival Log: Maintain a log with details of archived files, including file names,

archival date, and location.

o Access Protocol: Implement a process for accessing archived files, if needed.

Examination Details

Performance Evaluation:

1\. File Creation and Categorization:

o Assessment Criteria: Evaluate the learner’s ability to create and categorize files

using the chosen classification system.

o Tangible Outputs: Review labeled folders and the categorization system used.

2\. Document Control and Access Management:

o Assessment Criteria: Assess how effectively the learner applies the

document control process and manages access.

o Tangible Outputs: Review the access log and document control forms

for accuracy and completeness.

3\. Document Placement and Retrieval:

o Assessment Criteria: Evaluate the learner's process for placing new documents

in files and retrieving them for follow-up.

o Tangible Outputs: Check the updated filing index, access logs, and any placed

documents for correctness.

4\. Filing Index Maintenance:

o Assessment Criteria: Assess how well the learner builds and maintainsan easy-

to-use filing index.

o Tangible Outputs: Review the filing index for clarity, completeness, and ease of

use.

5\. Archiving Process:

14

o Assessment Criteria: Evaluate the learner’s approach to archiving files and

maintaining archival records.

o Tangible Outputs: Inspect the archived files, archive logs, and archival storage for

proper labeling, organization, and adherence to the archiving process.

Document Review:

● Submission Requirements: The learner should submit all relevant documentation, including:

o Created and categorized files.

o Access logs and document control forms.

o Updated filing index.

o Archived files and archival log.

● Assessment Focus: The assessor will review the documentation for completeness,

accuracy, and adherence to the manual filing system procedures.

Feedback and Reflection:

● Debriefing Session: The learner will participate in a session to discuss their performance.

● Feedback: The assessor will provide feedback on strengths and areas for improvement.

● Reflection: The learner should reflect on their approach, challenges faced, and strategies

for improving file management practices.

This detailed scenario-based practical task will provide a comprehensive assessment of your ability

to manage a manual filing system effectively, covering all aspects from file creation to archiving.

checklist.

Scenario-Based Practical Task: Administering OHS Meetings in an Office Setting

Scenario Overview

In this role-play scenario, you will demonstrate your ability to administer Occupational Health and

Safety (OHS) meetings effectively. You will be tasked with developing meeting agendas, arranging

and scheduling meetings, taking minutes, maintaining attendance records, and following up on

action lists. This task will help you practice the essential skills needed to manage OHS meetings

and ensure that they are productive and well-documented.

Simulated Environment Setup

Environment:

● Office Layout: A standard office setup with a meeting room and individual workstations.

● Meeting Room: Equipped with a table, chairs, a whiteboard or flip chart, and a computer

with presentation capabilities.

22

Tools and Equipment:

● Computer: Pre-loaded with MS Office suite (Word, Excel) and email client.

● Document Templates: Provided for meeting agendas, minutes, attendance records,

and action lists.

● Communication Tools: Email and calendar software for scheduling meetings.

● Stationery: Notepads, pens, and a printer.

Staging:

● Meeting Scenario: A simulated OHS meeting with pre-set details, such as agenda

items, participants, and action items.

● Role-Play Participants: You will assume the role of the OHS Practitioner and act as the

meeting organizer, note-taker, and follow-up coordinator.

● Meeting Materials: Sample agenda items, action list, and attendance record templates

will be provided.

Role-Play Details for Simulated OHS Meeting

In this role-play, you will simulate an OHS meeting where you are responsible for administering all

key aspects of the meeting, including preparation, organization, and follow-up. The meeting will

focus on recent safety incidents, ongoing safety projects, and upcoming safety audits.

Simulated Meeting Details

Meeting Title: Quarterly Occupational Health and Safety Review

Date and Time: \[Specify a time that suits the simulation; e.g., August 30, 2024, at 10:00 AM\]

Duration: 90 minutes

Location: Conference Room A (simulated)

Participants

1\. OHS Practitioner (You) - Role: Meeting Organizer and Facilitator

2\. Safety Officer - Role: Provides updates on recent safety incidents

3\. HR Manager - Role: Discusses safety training and compliance issues

4\. Facilities Manager - Role: Updates on ongoing safety projects and facility improvements

5\. Representative from the Safety Committee - Role: Presents feedback and safety concerns

from employees

23

Note: In this role-play, you will simulate the roles of the attendees if required. For simplicity,

assume that you have received all necessary information from these participants.

Pre-Meeting Preparation

1\. Develop Agenda:

o Agenda Items:

▪ Welcome and Introductions (5 minutes)

▪ Review of Previous Meeting Minutes (10 minutes)

▪ Update on Recent Safety Incidents (15 minutes)

▪ Review of Ongoing Safety Projects (20 minutes)

▪ Safety Training and Compliance (15 minutes)

▪ Feedback from the Safety Committee (10 minutes)

▪ Action Items and Next Steps (10 minutes)

▪ Any Other Business (5 minutes)

2\. Send Invitations:

o Create and Send Calendar Invitations: Include the agenda, date, time,

and location.

Meeting Execution

1\. Start the Meeting:

o Welcome Attendees: Greet participants and outline the meeting’s objectives.

o Review Agenda: Walk through the agenda and adjust as needed basedon

participants' input.

2\. Take Minutes:

o Record Key Points: Document discussions, decisions, and action items using the

provided template.

24

3\. Facilitate Discussions:

o Safety Incidents Update: Ask the Safety Officer to present recent incident reports

and findings.

o Ongoing Projects: Request the Facilities Manager to provide updateson safety-

related projects.

o Training and Compliance: Invite the HR Manager to discuss safetytraining

initiatives and compliance issues.

o Feedback: Allow the Safety Committee Representative to present

employee feedback and concerns.

4\. Action Items:

o Assign Responsibilities: Ensure that action items are clearly assignedto

individuals with specific deadlines.

5\. Conclude the Meeting:

o Summarize: Recap key decisions, action items, and next steps.

o Thank Participants: Express appreciation for their contributions and attendance.

o Confirm Next Meeting: Schedule the next meeting if needed.

Post-Meeting Tasks

1\. Distribute Minutes:

o Finalize and Share: Complete the minutes based on your notes and distribute

them to all participants.

2\. Maintain Records:

o File Attendance and Minutes: Ensure records are accurately filed and stored.

3\. Follow-Up:

o Track Action Items: Monitor progress on action items and send remindersas

necessary.

Role-Play Scenarios

1\. Scenario 1: Safety Incident Report

o Situation: The Safety Officer reports a recent incident where a minor injury

occurred due to a slip hazard. You need to discuss this incident, review what

happened, and propose preventive measures.

25

2\. Scenario 2: Ongoing Safety Project Update

o Situation: The Facilities Manager provides an update on the installation of new

safety barriers. Discuss the project's status, any issues faced, and how it impacts

overall safety.

3\. Scenario 3: Training and Compliance Discussion

o Situation: The HR Manager raises concerns about upcoming safety training

sessions and compliance with new regulations. You need to address these concerns

and ensure alignment with safety standards.

4\. Scenario 4: Feedback from the Safety Committee

o Situation: The Safety Committee Representative presents feedback about recent

safety improvements that have not met employee expectations. You need to discuss

this feedback and decide on any necessary actions.

Tasks and Execution

PA03-01: Develop Meeting Agendas

1\. Review Meeting Objectives:

o Understand Objectives: Familiarize yourself with the purpose of the OHS meeting

(e.g., reviewing recent incidents, discussing safety improvements).

2\. Draft Agenda:

o Create Agenda: Use the provided template to draft the meeting agenda. Include

sections such as:

▪ Meeting Title

▪ Date and Time

▪ Location

▪ Participants

▪ Agenda Items (e.g., incident reports, safety audits, action items)

▪ Any Other Business

26

o Distribute Agenda: Email the draft agenda to participants in advance ofthe

meeting.

PA03-02: Arrange and Schedule Meetings

1\. Determine Meeting Logistics:

o Identify Participants: Determine who needs to attend the meeting based on the

agenda.

o Schedule Time: Use a calendar tool to find a suitable time for all participants.

Consider time zones if applicable.

2\. Send Invitations:

o Email Invitations: Send out calendar invitations with the meeting details, agenda,

and any required pre-reading materials.

3\. Confirm Arrangements:

o Confirm Attendance: Follow up to confirm that all participants have received the

invitation and will attend.

PA03-03: Take Minutes at Meetings

1\. Prepare for Note-Taking:

o Set Up: Ensure you have a notepad or electronic device ready for taking minutes.

o Review Agenda: Familiarize yourself with the agenda items and participants.

2\. Capture Minutes:

o Document Key Points: Record key discussions, decisions, and action items as

they occur. Use a structured format:

▪ Date and Time

▪ Attendees

▪ Agenda Item

▪ Summary of Discussion

▪ Decisions Made

▪ Action Items and Responsible Parties

27

o Review: Ensure accuracy and completeness before concluding the meeting.

PA03-04: Maintain Records of Attendance at Meetings

1\. Record Attendance:

o Attendance Sheet: Use the provided template to record who attendedthe

meeting. Include:

▪ Participant Names

▪ Time In

▪ Time Out

o Verify Attendance: Cross-check with participants if necessary to ensure accuracy.

2\. File Attendance Records:

o Organize Records: Store attendance records in a designated file or digital folder

for future reference.

PA03-05: Follow Up on Meeting Action Lists

1\. Review Action Items:

o Action List: Review the action items recorded during the meeting. Ensure each
