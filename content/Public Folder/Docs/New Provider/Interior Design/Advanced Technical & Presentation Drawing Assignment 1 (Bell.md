Assignment 1
TASK 1: Drawing Types and Professional Communication (10 Marks)
Scenario
You have been appointed as a junior interior designer for a small coffee shop project in Cape
Town. The client requires several drawings before construction can begin.
Answer the following questions:
1. Name THREE different types of drawings used in interior design projects. (3)
2. Explain the purpose of each drawing type named above. (3)
3. Explain why working drawings are important for contractors. (2)
4. State TWO problems that may occur if drawings are unclear or inaccurate. (2)
TASK 2: Professional Drawing Sheet Layout (15 Marks)
Create a professional drawing sheet for an interior design project.
Requirements
Your sheet must include:
● A border and margins
● A title block
● Project name
● Drawing title
● Drawing number
● Scale
● Date
● Designer name
● Neatly arranged layout
● Correct spacing and alignment
