Instructions
1. Complete ALL practical tasks using SketchUp.
2. Save your work regularly while completing the assignment.
3. Submit the following:
● Your SketchUp (.skp) file
● Exported images
● Screenshots where required

5. Use appropriate materials, textures, lighting, and presentation techniques.
6. Marks will be awarded for creativity, accuracy, organisation, workflow, and
presentation quality.

Assignment 2
SECTION A: MATERIALS, TEXTURES, AND VISUAL DESIGN [25 Marks]
Question 1: Applying Materials and Textures (15 Marks)
Create a furnished interior room model and apply suitable materials and textures.
Requirements:
Apply materials to:
● Floor
● Walls
● Furniture
● Windows/Glass
● Decorative objects
Tasks:
1. Apply suitable floor material. (3)
2. Apply wall textures correctly. (3)
3. Apply realistic furniture materials. (3)
4. Use glass/transparency materials correctly. (3)
5. Overall visual appearance is realistic and neat. (3)
Evidence Required:
● Screenshots of completed textured room
● Material tray visible in at least one screenshot
Question 2: Visual Design Principles (10 Marks)
Improve the visual quality of your model using good design principles.
Tasks:
1. Use a balanced furniture layout. (2)
2. Use suitable colour combinations. (2)
3. Maintain proper spacing and proportion. (2)
6

4. Create a visually attractive room design. (2)
5. Ensure the model looks realistic and professional. (2)
Evidence Required:
● Final rendered screenshots from multiple angles
SECTION B: LIGHTING AND SUSTAINABLE DESIGN [20 Marks]
Question 3: Lighting and Shadows (10 Marks)
Use SketchUp shadow and lighting settings to improve your presentation.
Tasks:
1. Enable shadows correctly. (2)
2. Adjust shadow settings appropriately. (2)
3. Position the model to create realistic lighting. (2)
4. Create one daytime scene. (2)
5. Overall lighting presentation is realistic. (2)
Evidence Required:
● Screenshots showing shadows enabled
● Daytime scene screenshot
Question 4: Sustainable and Inclusive Design Features (10 Marks)
Add sustainable or inclusive design elements to your model.
Choose ANY TWO:
● Large windows for natural lighting
● Wheelchair-accessible doorway
● Energy-efficient lighting layout
● Open movement space
● Eco-friendly material appearance
● Indoor plants or green design features
7

Marks Allocation:
1. First feature added correctly. (3)
2. Second feature added correctly. (3)
3. Features positioned realistically. (2)
4. Model demonstrates awareness of inclusive/sustainable design. (2)
Evidence Required:
● Screenshots clearly showing the selected features
SECTION C: ADVANCED TOOLS AND WORKFLOW IMPROVEMENT [25 Marks]
Question 5: Using the 3D Warehouse (10 Marks)
Import and use objects from the 3D Warehouse.
Requirements:
Import at least:
● One furniture object
● One decorative object
● One lighting object
Tasks:
1. Furniture object imported correctly. (2)
2. Decorative object imported correctly. (2)
3. Lighting object imported correctly. (2)
4. Imported objects scaled and positioned properly. (2)
5. Model remains neat and organised. (2)
Evidence Required:
● Screenshots of imported objects
● Components panel visible
8

Question 6: Workflow Optimisation and Advanced Modelling (15 Marks)
Demonstrate efficient modelling workflow techniques.
Tasks:
1. Use groups/components correctly. (3)
2. Use tags to organise the project. (3)
3. Demonstrate proper file organisation. (3)
4. Use advanced modelling tools effectively. (3)
5. Maintain clean geometry and professional workflow. (3)
Evidence Required:
● Screenshots showing tags/groups
● Organised Outliner panel
● Clean model structure
SECTION D: PRESENTATION, EXPORTING, AND PROFESSIONAL PRACTICE [30 Marks]
Question 7: Creating Presentation Views and Scenes (10 Marks)
Create professional presentation scenes for your project.
Required Scenes:
● Front View
● Interior View
● Top View
● Perspective View
Marks Allocation:
1. Front View created correctly. (2)
2. Interior View created correctly. (2)
3. Top View created correctly. (2)
4. Perspective View created correctly. (2)
5. Smooth scene organisation and presentation. (2)
9

Evidence Required:
● Scene tabs visible
● Screenshots of all scenes
Question 8: Exporting and Sharing Projects (10 Marks)
Export presentation images from your model.
Tasks:
1. Export high-quality image correctly. (3)
2. Use proper file naming conventions. (2)
3. Save exports in organised folders. (2)
4. Ensure image quality is professional. (3)
Evidence Required:
● Exported images
● Screenshot of export folder
Question 9: Professional Design Presentation (10 Marks)
Prepare a final presentation view of your completed project.
Tasks:
1. Present a neat and organised final model. (3)
2. Use good camera angles. (2)
3. Use effective lighting and shadows. (2)
4. Apply suitable materials and textures. (2)
5. Overall presentation is professional and visually appealing. (1)
Evidence Required:
● Final presentation screenshots
● Final exported image
