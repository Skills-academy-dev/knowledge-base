Instructions
1. Complete ALL practical tasks using SketchUp.
2. Save your work regularly while completing the assignment.
3. Submit the following:
● Your SketchUp (.skp) file
● Screenshots where required
● Exported images
● A compressed (ZIP) project folder if required
4. Use clear and professional file names.
5. Ensure all models are neat, organised, and correctly measured.
6. Marks will be awarded for accuracy, organisation, correct tool usage, and
presentation quality.

Assignment 1
SECTION A: PROJECT SETUP AND WORKSPACE SKILLS [20 Marks]
Question 1: Creating and Organising Project Files (10 Marks)
Create a new project folder for this assignment.
Your folder must contain the following subfolders:
● Models
● Textures
● Exports
● References
Tasks:
1. Create the folder structure correctly. (4)
2. Save your SketchUp file using a professional file name. (2)
3. Select the correct SketchUp template for architectural/interior design work. (2)
4. Save the file in the correct folder location. (2)
Evidence Required:
● Screenshot of folder structure
● Screenshot of template selection
● Screenshot of saved file location
Question 2: Workspace Navigation (10 Marks)
Open SketchUp and demonstrate the following navigation tools:
Tasks:
1. Use the Orbit Tool. (2)
2. Use the Pan Tool. (2)
3. Use the Zoom Tool. (2)
4. Show the Instructor panel open. (2)
5. Show the status bar displaying tool information. (2)
6

Evidence Required:
● Screenshots showing each tool in use
SECTION B: BASIC DRAWING AND ACCURACY [25 Marks]
Question 3: Creating 2D Shapes (10 Marks)
Create the following shapes in SketchUp using accurate dimensions:
Shape Requirement
Rectangle 5000 mm × 4000 mm
Circle Radius = 1000 mm
Polygon 6 sides
Arc Shape Curved feature
Marks Allocation:
1. Rectangle created accurately. (2)
2. Circle created accurately. (2)
3. Polygon created correctly. (2)
4. Arc tool used correctly. (2)
5. Shapes organised neatly. (2)
Evidence Required:
● Screenshot of completed shapes
7

Question 4: Measurements and Accuracy (15 Marks)
Create a simple room floor layout using exact dimensions.
Room Requirements:
● Width: 6000 mm
● Length: 5000 mm
Tasks:
1. Use exact dimensions while drawing. (4)
2. Demonstrate inference snapping. (3)
3. Correctly use the red, green, and blue axes. (3)
4. Ensure all walls align correctly. (3)
5. Keep the layout neat and accurate. (2)
Evidence Required:
● Screenshot of floor plan
● Screenshot showing dimensions
SECTION C: 3D MODELLING AND MODIFICATION TOOLS [30 Marks]
Question 5: Create a Simple 3D Room Model (20 Marks)
Using the floor layout created in Question 4, create a basic 3D room model.
Requirements:
● Create walls
● Add one door opening
● Add two window openings
● Add simple furniture
● Add a floor surface
8

Tasks:
1. Use Push/Pull correctly to create walls. (5)
2. Create door opening accurately. (3)
3. Create window openings accurately. (3)
4. Add at least 3 furniture items. (3)
5. Use Move and Rotate tools correctly. (3)
6. Model is neat and realistic. (3)
Evidence Required:
● Screenshots from different angles
● Final SketchUp model
Question 6: Modification Tools (10 Marks)
Demonstrate the following modification tools in your model:
Tool Task
Move Tool Reposition furniture
Rotate Tool Rotate one furniture item
Scale Tool Resize one object
Copy/Array Function Duplicate chairs or tables
Marks Allocation:
1. Move Tool used correctly. (2)
2. Rotate Tool used correctly. (2)
3. Scale Tool used correctly. (2)
4. Array/Copy function used correctly. (2)
5. Objects positioned neatly. (2)
9

Evidence Required:
● Before and after screenshots
SECTION D: ORGANISING 3D MODELS [25 Marks]
Question 7: Groups and Components (10 Marks)
Organise your model professionally.
Tasks:
1. Group walls separately. (3)
2. Convert furniture into components. (3)
3. Prevent geometry from sticking together. (2)
4. Keep model organised and clean. (2)
Evidence Required:
● Screenshot showing groups/components panel
Question 8: Tags and Scenes (10 Marks)
Create tags and scenes for your project.
Tasks:
1. Create a Walls tag. (2)
2. Create a Furniture tag. (2)
3. Create a Front View scene. (2)
4. Create an Interior View scene. (2)
5. Scenes display correctly. (2)
Evidence Required:
● Screenshots of tags
● Screenshots of scenes
10

Question 9: Final Presentation Export (5 Marks)
Export your completed model as an image.
Tasks:
1. Export a high-quality image of the model. (2)
2. Ensure the model is clearly visible. (1)
3. Use a good camera angle. (1)
4. Save the export in the correct folder. (1)
Evidence Required:
● Exported image
