  Name and describe the main components of a computer, including the monitor,

  Understand the function of each part in the overall operation of a computer.

  Start up and shut down a computer properly.

  Navigate the basic features of a computer’s operating system.

Identify the main keys on a keyboard and understand their functions.

  Demonstrate the correct hand placement for typing efficiently.

  Understand the basic functions of a mouse, including clicking, double-clicking,

right-clicking, and scrolling.

  Practise using a mouse to select and open items on the screen.

  Define and differentiate between input devices (like keyboards and mice), output

devices (like monitors and printers), and storage devices (like hard drives and USBs).

  Explain the role each type of device plays in computer operation.

  Recognise different types of computing devices such as desktops, laptops, tablets,

and smartphones.

  Understand the basic uses and advantages of each type of device.

INTRODUCTION

In this module, you will start your journey into the world of computers. It will help you

understand the basic concepts and components of computers, which are essential in

today’s technology-driven world. By the end of this module, you will be more comfortable

using a computer for everyday tasks.

Unit 1.1: The Role of Computers

This unit explores how computers have become a vital part of our daily lives. You will learn

about the various ways computers are used in different fields such as education, business,

and healthcare. Understanding the role of computers will help you appreciate their

importance in modern society.

Read pages 12—14 of your textbook for  more information.

Unit 1.2: Parts of a Computer

This unit covers the basic parts that make up a computer, including the monitor, keyboard,

mouse, and CPU. You will learn what each part does and how they work together to help

the computer function. By knowing the parts of a computer, you will be better equipped to

use it effectively.

Read pages 15—18 of your textbook for  more information.

Unit 1.3: Using a Computer

This unit explains how to start up, navigate, and shut down a computer properly. You will

also learn about basic tasks like using a keyboard and mouse, and how to move around the

desktop. This unit ensures that you can operate a computer smoothly and efficiently.

Read pages 19—22 of your textbook for  more information.

Unit 1.4: Overview of a Keyboard

This unit introduces the keyboard, one of the most important tools for interacting with a

computer. You will learn about the different types of keys and their functions. Knowing how

to use the keyboard effectively will make your typing faster and more accurate.

Read pages 22—23 of your textbook for  more information.

Read pages 24—25 of your textbook for  more information.

Unit 1.6: Input, Output, and Storage Devices

This unit explains the different devices that allow you to input information into the computer,
