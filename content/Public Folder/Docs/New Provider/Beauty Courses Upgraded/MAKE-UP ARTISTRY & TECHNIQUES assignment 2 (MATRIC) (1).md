What this task focuses on:
Shaping brows, choosing correct brow colour/finish, applying eyeliner, eyeshadow (4‐colour
method), and mascara using professional technique.
Instructions

2. Apply brown finish.
3. Apply eyeliner.
4. Apply eyeshadow using the 4‐colour method.
5. Apply mascara.
