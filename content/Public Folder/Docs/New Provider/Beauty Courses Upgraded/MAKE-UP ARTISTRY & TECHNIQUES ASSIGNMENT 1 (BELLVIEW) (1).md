ASSIGNMENT 1
ASSIGNMENT 1: PRACTICAL APPLICATION
1. INTRODUCTION TO THIS ASSIGNMENT
This is a 100% practical assignment designed to test your ability to apply the techniques
taught in Modules 1–5 of the Make-Up Artistry textbook.
You will demonstrate real-world professional skills including:
● Facial analysis
● Corrective contour design
● Client consultation
● Skin preparation
● Shade matching
● Colour correction
● Base application
● Sculpting using contour, highlight and blush
● Colour theory application
2. GENERAL RULES
1. All work must be performed on a real model.
2. All photos must be clear, unfiltered, labelled, and taken in good lighting.
3. You must submit every required image. Missing images = automatic zero for that
section.
4. Strict hygiene must be followed at all times.
5. Written explanations must be in full sentences.
6. Reflections are compulsory but not marked.
7. Image numbers must match the task list (Image 1, Image 2, etc.).
3. GENERAL SUBMISSION INSTRUCTIONS
You must submit:
● All required images labelled correctly
● Written explanations where required
● Your completed skin consultation form
● All reflections
Submit tasks in the correct order.

TASK 1: FACIAL ANALYSIS & CORRECTIVE DESIGN
Marks: 15
What this task is about:
This task teaches you how to analyse a client’s face shape and design a corrective contour
and highlight plan based on facial proportions. This is a core professional skill for achieving
balance and symmetry in makeup.
Instructions
1.  Take a clear "before" photo of your model.
2.  Identify the model’s face shape and justify your choice.
3.  Apply contour mapping only (do not blend).
4.  Apply highlight mapping only (do not blend).
5.  Provide a short written explanation of your corrective strategy.
Images Required
●  Image 1: Before photo
●  Image 2: Face shape identification (marked or labelled)
●  Image 3: Contour placement (unblended)
●  Image 4: Highlight placement (unblended)

TASK 3: BASE APPLICATION & COLOUR CORRECTION
Marks: 15
What this task is about:
This task develops your ability to match foundation to undertone, correctly apply colour
correction, and blend a flawless base using the techniques from Modules 3 and 4.
Instructions
1.  Perform a shade-matching test along the jawline.
2.  Apply the correct colour correctors (do not blend for the photo).
3.  Apply and blend the full base (foundation + concealer + setting).
4.  Write a brief explanation of your shade choices and techniques.
Images Required
●  Image 10: Shade-matching swatches
●  Image 11: Colour corrector application (unblended)
●  Image 12: Final blended base

TASK 4: SCULPTING, BLUSHER & COLOUR THEORY APPLICATION
Marks: 15
What this task is about:
This task assesses your ability to sculpt the face using contour, highlight, blush, and bronzer,
while applying colour theory and undertone matching principles.
Instructions
1.  Apply contour mapping only (do not blend).
2.  Apply highlight mapping (unblended).
3.  Apply blush (unblended for the photo).
4.  Complete the fully blended sculpting look.
5.  Explain your colour choices using colour theory.
Images Required
●  Image 13: Contour placement (unblended)
