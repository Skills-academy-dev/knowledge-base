# The Ultimate Career Booklet

## Assignment 1 - Answer Key

## Answer Key

B — Good career choices start with self-awareness (strengths, values, goals).

B — A short "strengths journal" reveals what energises you in real work.

B — Pair weaknesses with concrete improvement steps to show growth.

B — Values–role mismatch drains energy and engagement.

C — Specific, measurable, time-bound goal with a clear deliverable.

A — Map your hard/soft skills against job requirements before applying.

B — Confidence compounds when you log small wins and rehearse key tasks.

B — Set limits and define "good enough" to prevent overusing a strength.

B — Research helps you aim at growing sectors and avoid shrinking ones.

B — Look past titles to daily tasks, skills, entry routes, progression.

B — Labour-market data shows demand trends, skill gaps, and regional prospects.

B — Compare multiple ads to extract repeated skills, then close your gaps.

B — Informational interviews are for learning pathways, not asking for a job.

B — Networks surface hidden roles via referrals and introductions.

B — If core tasks fight your values/energy, the role likely won't fit.

B — Clear structure, plain language, and error checks improve impact.

B — Paraphrase + clarifying questions = true active listening.

B — Open posture, steady eye contact, congruent tone support your message.

B — Define the problem with evidence before proposing fixes.

B — "Five Whys" probes assumptions to reach root causes.

B — A decision matrix compares options against agreed criteria.

B — Pilot small with success metrics before rolling a change wider.

B — Separate urgent from important (e.g., Eisenhower Matrix) to focus.

B — Three core outcomes (plus one optional) keep days realistic.

B — Time-boxing contains low-value work so it doesn't sprawl.

B — Use blockers and silence non-essential alerts to protect focus.

B — High-trust teams share info, respect differences, and own commitments.

B — Focus on issues/ideas, resolve respectfully; avoid personal attacks.

B — Owner + deliverable + due date, tracked where all can see.

B — Real growth = learn → apply → get feedback → improve (loop).

A — Formal learning: degrees and accredited certificates.

B — Non-formal: structured courses/workshops outside degree programmes.

B — Informal: books, tutorials, shadowing, peer discussions.

B — First filter is fit to your goal and target skill gap.

A — Vet entry requirements, outcomes, delivery mode, and assessment.

B — Fund smartly via bursaries/scholarships/employer support and a cost plan.

B — Time-block study, use buffers, and scale down in heavy weeks.

B — Recognising prior learning can grant credit/advanced standing.

B — Learning sticks when you apply concepts in small, real tasks and get feedback.

B — Quarterly system = focused skill + resources + practice tasks + review.

B — Events, associations, and informational chats build learning and access.

B — Future-friendly = rising employment + skills shortages in credible data.

B — Compare roles by how tasks/skills/growth match your strengths/values.

B — Define success measures before piloting to judge impact.

B — Lead updates with bottom line, status vs measures, and next steps.

B — Confirmation bias = noticing only data that fits your first idea.

B — Test fit cheaply: short intro course + speak to practitioners.

B — Track applied outputs (draft, prototype, mini-project), not just hours.

B — Ignoring feedback/avoiding collaboration is NOT recommended.

B — Best foundation: align strengths/values with market-aware goals, build core skills, and keep a learn–apply–improve cycle.
