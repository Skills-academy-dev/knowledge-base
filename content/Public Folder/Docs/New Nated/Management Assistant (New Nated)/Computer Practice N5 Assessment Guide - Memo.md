2.2 Explain the difference between volatile and non-volatile memory. Provide one example of each. (4 Marks)

Volatile Memory: Temporary memory that loses data when power is turned off. Example: RAM (2)

Non-volatile Memory: Permanent storage that retains data even without power. Example: HDD, SSD, ROM (2)

2.3 Describe two advantages and two disadvantages of using a GUI-based operating system. (4 Marks)

Advantages (Any two = 2 marks)

User-friendly and easy to navigate.

Supports multitasking with multiple open windows.

Visually appealing with icons and menus.

Disadvantages (Any two = 2 marks)

Requires more memory and processing power.

Can be slower than command-line interfaces for advanced users.

May have limited control over system settings.

2.4 Functions of the following components in a computer system. (4 Marks)

Each correct function = 1 mark.

CPU: Processes instructions and performs calculations.

Hard Drive: Stores all data, including the operating system and applications.

Motherboard: Connects and allows communication between all components.

RAM: Temporary memory that stores data for currently running applications.

QUESTION 2: WEB SECURITY AND CLOUD COMPUTING (20 Marks)

2.1 Define the following terms related to web security and cloud computing. (6 Marks)

Each correct definition = 2 marks.

Encryption: The process of converting data into a coded format to prevent unauthorized access.

Two-factor authentication: A security measure that requires users to verify their identity using two different methods (e.g., password and OTP).

Internet of Things (IoT): A network of connected devices that communicate over the internet (e.g., smart home appliances).

2.2 List three benefits of using cloud storage over traditional storage devices. (3 Marks)

Each correct benefit = 1 mark.

Accessibility from anywhere with an internet connection.

Automatic backups and disaster recovery.

Scalability to store large amounts of data without physical space constraints.

2.3 Explain how a firewall protects a computer network from cyber threats. (3 Marks)

A firewall acts as a security barrier that monitors and filters incoming and outgoing traffic. (1)

It blocks unauthorized access while allowing safe communications. (1)

It prevents malware, hacking attempts, and data breaches. (1)

2.4 A small business wants to start an e-commerce website. List four security measures they should implement to protect customer data. (4 Marks)

Each correct security measure = 1 mark.

Use SSL encryption to secure transactions.

Implement strong authentication methods (e.g., two-factor authentication).

Regularly update software and apply security patches.

Monitor and prevent fraud using AI-based security tools.

2.5 Provide two advantages and two disadvantages of using a VPN for online security. (4 Marks)

Each correct answer = 1 mark.

Advantages:

Increases online privacy by masking IP addresses.

Protects data on unsecured networks, such as public Wi-Fi.

Disadvantages:

May reduce internet speed due to encryption processes.

Some websites block VPN users to prevent region-based access restrictions.
