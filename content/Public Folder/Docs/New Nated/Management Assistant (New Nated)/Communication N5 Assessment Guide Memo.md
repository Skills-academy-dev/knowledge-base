2.1 Workplace Communication (10 Marks)

(2 marks each: 1 for definition, 1 for example)

|  |  |  |
| :-: | :-: | :-: |
| Type of Communication | Definition | Example |
| Formal Communication | Official communication in a structured manner. | Company policies, official emails. |
| Informal Communication | Casual and unofficial communication. | Office gossip, casual chats. |
| Internal Communication | Communication within an organisation. | Staff meetings, internal memos. |
| External Communication | Communication with outside entities. | Emails to clients, press releases. |
| Cross-cultural Communication | Communication between different cultural backgrounds. | International business meetings. |

(1 mark each – Any 5 of the following should be given full marks.)

Helps prioritise business objectives.

Provides a clear roadmap for employees.

Call to action.

2.4 Effective Presentation Skills (8 Marks)

(a) Importance of body language (3 Marks – Give any 3)

Helps convey confidence.

Engages the audience.

Reinforces spoken words.

Improves credibility.

Enhances message retention.

(b) Five engagement techniques (5 Marks)

(1 mark each – Accept any 5 valid techniques)

Using appropriate hand gestures.

Making eye contact.

Modulating voice tone.

Using storytelling.

Incorporating visual aids.

Asking questions to involve the audience.

Using humour appropriately.

2.5 Business Writing Skills (10 Marks)

(2 marks each – Any 5 of the following should be given full marks.)

Clarity – Messages should be easy to understand.

Conciseness – Avoid unnecessary details.

Professional Tone – Maintain formal, respectful language.

Correct Formatting – Use standard business structures (e.g., memos, reports).

Grammar and Proofreading – Eliminate errors before submission.

Appropriate vocabulary – Use business-appropriate language.

Logical structure – Organise content in a meaningful way.

2.6 Cultural Awareness in Business Communication (7 Marks)

(3 marks for barriers, 4 marks for solutions)

Three barriers (1 mark each)

Language differences.

Different work ethics and time management practices.

Non-verbal misinterpretations.

Four ways to overcome barriers (1 mark each)

Use simple, clear language.

Provide cross-cultural training.

Be open-minded and adaptable.

Encourage inclusive decision-making.

2.7 The Importance of Practical Workplace Communication (5 Marks)

(2 marks for importance, 3 marks for examples)

Importance:

Enhances teamwork and efficiency.

Prevents misunderstandings.

Examples:

(1 mark each – Any 3 valid examples should be accepted.)

Emails ensure proper documentation of discussions.

Reports provide structured information for decision-making.

Meetings allow direct engagement with employees.

Employee newsletters keep staff informed.

2.8 Listening Skills (5 Marks)

(1 mark each – Any 5 valid answers should be accepted.)

Maintain eye contact.

Avoid interruptions.

Show empathy through nodding and expressions.

Repeat key points to confirm understanding.

Ask relevant follow-up questions.

Take notes during conversations.
