## Introduction

## SECTION A: TYPING TECHNIQUE

Section A focuses on developing accuracy, speed, and technique when keying in text.

The main goal is to train students to type quickly, accurately, and professionally — without looking at the keyboard.

## Module 1: Accuracy and Speed Development

Learning Objectives

By the end of this module, students should be able to:

Achieve a minimum speed of 50–55 words per minute with a high level of accuracy.

Complete the 10-minute timed accuracy test with no more than 26 typing errors.

Demonstrate correct touch-typing posture, hand positioning, and finger coordination.

Apply daily typing drills and timed tests to improve both accuracy and speed.

Use the spell checker effectively to identify and correct typing errors.

Maintain correct punctuation and spacing in all keyed-in documents.

### Introduction

Typing speed and accuracy are essential for professional performance in the office environment.
This module helps students refine their typing technique by focusing on accuracy, rhythm, posture, and concentration. Students will learn to apply proofreading rules, develop consistent typing habits, and practise timed tests to prepare for the national N6 examination.

### Unit 1: Mark Schedule for Timed Accuracy Tests

1.1 Understanding the timed accuracy test
1.2 Marking criteria and calculation of words per minute
1.3 Accuracy and error deduction

### Unit 2: Improving Speed and Accuracy – Touch-Typing Skills

2.1 The importance of correct posture and hand placement
2.2 Maintaining a steady rhythm
2.3 Avoiding common typing errors

### Unit 3: The Importance of Using the Spell Check Function

3.1 Using automatic spelling and grammar tools
3.2 Correcting flagged errors
3.3 Manual proofreading

### Unit 4: Punctuation Spacing

4.1 Correct spacing after punctuation marks
4.2 Rules for letter and word spacing
4.3 Common spacing mistakes and corrections

### Unit 5: Improving Speed and Accuracy – Practise the Alphabet

5.1 Finger coordination and drill exercises
5.2 Alphabet sequence practice
5.3 Continuous practice and time tracking

### Unit 6: Improving Speed and Accuracy – Practise Drills

6.1 One-minute drills for accuracy
6.2 Short timed sessions (15s, 30s, 60s)
6.3 Accuracy reinforcement

### Unit 7: Ten-Minute Timed Accuracy Tests

### Unit 8: Names of Keyboard Symbols

## SECTION B: WORD PROCESSING

Section B focuses on applying computer and software skills to produce professional business documents using a word processing program, such as Microsoft Word.

It extends the typing skills from Section A into full document creation, editing, and formatting — preparing students for real workplace environments.

## Module 9: Initial Instructions, Proofreading Signs and Typing Rules

Learning Objectives

By the end of this module, students should be able to:

Identify and describe the basic components of a computer, including hardware and software.

Handle, format, and save data on storage devices safely and correctly.

Create, edit, save, and print documents using Microsoft Word.

Apply basic and advanced formatting tools, including margins, spacing, justification, and layout management.

Use pull-down menus, the status bar, and help functions effectively.

Apply proofreading and typing rules to produce neat, accurate, and professional work.

Insert and format headers, footers, and page numbers for multi-page documents

### Introduction

This module forms the foundation for all word processing work.

Students will learn how to create, edit, and format documents in Microsoft Word, applying both basic and advanced layout tools. By mastering page layout management, headers, and footers, students will be able to produce professional documents suitable for the modern workplace.

### Unit 1: Basic Computer Knowledge

1.1 Hardware and software identification
1.2 Handling storage devices
1.3 Formatting disks and file safety

### Unit 2: Application and Manipulation Functions

2.1 Creating, saving, editing, and printing
2.2 Formatting tools (margins, spacing, justification)
2.3 Using pull-down and help menus

### Unit 3: Microsoft Word Advanced Tools

3.1 Page Layout Management

Adjusting margins, orientation, and paper size

Setting spacing, alignment, and indents

Using section breaks for multiple layout types within one document

Applying themes and consistent styles for presentation

3.2 Headers and Footers

Inserting and editing headers and footers

Adding elements such as company name, page title, and dates

Customising layout with “Different First Page” and “Different Odd/Even Pages” options

Maintaining uniformity in multi-page documents

3.3 Page Numbering

Inserting and positioning page numbers
